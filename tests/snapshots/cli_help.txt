===== aurelia =====
Aurelia CLI Steam launcher
Version: <version>

Usage: aurelia [OPTIONS] <COMMAND>

Commands:
  login           Authenticate with Steam and persist the session
  capabilities    Describe this build for drivers: commands, flags, JSON events, error types and exit codes, and the `--json` schema version. Offline. Without `--json` it prints a PowerShell-style list and error table. Name a command path (e.g. `capabilities config game`) for its flags, values and help
  list            List games in your library
  info            Show detailed information about a game
  price           Show a game's price, optionally across regions
  search          Search the store by title
  deals           Discounted and top-selling games in a region
  players         Current player count for an app
  events          Store-wide sales and events currently running
  news            Recent news (storefront web; no CM equivalent)
  reviews         User reviews, paged (storefront web, no CM equivalent)
  user            Profile by SteamID64, /profiles/ URL, friend name, `me`
  wishlist        Your wishlist, or a friend's
  similar         Games similar to a given app
  install         Download and install a game
  libraries       List the Steam library folders games can be installed into (one per drive/location). Use `--json` for tooling
  update          List installed games with an update available, or update one by app id
  play            Launch a game and wait for it to exit
  shaders         Pre-compile a game's Vulkan shaders from its Steam pipeline cache (`steamapps/shadercache/<appid>`), as Steam's "Processing Vulkan shaders" does. `play` does this automatically unless `config shader-precache off`
  launch-targets  List the ways an installed game can be launched: each installed build (native Linux / Windows) and, for Windows, each available Steam mode, with the `play` flags selecting it and which one plain `play` would pick
  stop            Stop a running game previously launched with `aurelia play`
  running         List the games Aurelia is currently running
  uninstall       Uninstall a game
  verify          Verify the integrity of an installed game
  duplicates      List games installed in more than one Steam library
  available       Report whether a game is installed and its files are present on disk
  drm             Verify a game's DRM tickets headlessly
  account         Show account details for the logged-in user
  dlc             List a game's DLC
  enable          Enable an installed DLC for its base game
  disable         Disable a DLC for its base game
  achievements    Show the logged-in user's achievements for a game
  image           Download a game's cover/header artwork to the local image cache
  move            Move an installed game to a different Steam library folder
  relink          Relink an install to a different Steam library
  import          Register an existing on-disk install with Steam
  branches        List available beta branches for a game
  set-branch      Switch a game to a different branch
  set-language    Swap an installed game's language depots
  depots          List depots for a game
  manifests       List each depot's current manifest id per branch (version discovery for `downgrade`). Steam only exposes current ids — older ones live on SteamDB
  downgrade       Install a specific (usually older) depot manifest and pin it — a downgrade
  pin             Pin a game to its currently-installed manifests, locking Aurelia's updates
  unpin           Remove a game's version pin (unlock Aurelia's updates)
  launch-options  List a game's launch options
  cloud           Manage Steam Cloud saves for a game
  workshop        Manage Steam Workshop items for a game
  proton          Download and manage Proton/Wine runtimes
  steam-runtime   Install, repair, or inspect the master Windows Steam runtime prefix
  luxtorpeda      Manage the optional luxtorpeda native-engine plugin
  umu             Manage the optional umu-launcher plugin (Proton via umu)
  scripts         Manage per-game launch scripts
  collections     Manage Steam library collections (categories/groups)
  friends         List friends, search for a SteamID, or add/remove friends
  chat            Send and read direct chat messages
  inventory       View your Steam inventory for a game
  wallet          Show your Steam Wallet balance
  market          Steam Community Market: prices, search, and your listings
  config          Inspect launcher configuration
  logout          Clear the stored session
  daemon          Run the background session daemon serving other commands over a local socket
  kill            Kill all running aurelia processes, including the session daemon
  help            Print this message or the help of the given subcommand(s)

Options:
  -j, --json        Emit output (and errors) as JSON. Works with every command
  -v, --verbose...  Increase log verbosity (repeatable: -v, -vv, -vvv). Without it only warnings and errors are logged. -v adds progress/debug logs and a launched game's own output; -vv/-vvv unmute the Steam networking stack so a stalled command shows where it is stuck. `RUST_LOG` / `AURELIA_LOG` override the logs
  -h, --help        Print help
  -V, --version     Print version

===== aurelia cloud sync =====
Sync a game's Steam Cloud saves with the local save directory. With neither flag it syncs down then up; `--down`/`--up` restrict the direction

Usage: aurelia cloud sync [OPTIONS] <APP_ID>

Arguments:
  <APP_ID>
          

Options:
  -u, --up
          Only upload local saves to Steam

  -d, --down
          Only download saves from Steam

  -p, --path <PATH>
          Local save directory. Defaults to Aurelia's managed cloud root

  -r, --resolve <RESOLVE>
          Resolve diverged saves by taking this side (`cloud` or `local`) instead of reporting them. Omit to only detect conflicts and leave both copies

          Possible values:
          - cloud: Overwrite the local copy with the cloud copy
          - local: Overwrite the cloud copy with the local copy

  -j, --json
          Emit output (and errors) as JSON. Works with every command

  -v, --verbose...
          Increase log verbosity (repeatable: -v, -vv, -vvv). Without it only warnings and errors are logged. -v adds progress/debug logs and a launched game's own output; -vv/-vvv unmute the Steam networking stack so a stalled command shows where it is stuck. `RUST_LOG` / `AURELIA_LOG` override the logs

  -h, --help
          Print help (see a summary with '-h')

===== aurelia config =====
Inspect launcher configuration

Usage: aurelia config [OPTIONS] <COMMAND>

Commands:
  show                             Print the current launcher configuration as JSON
  protons                          List detected Proton/Wine runtimes
  presence                         View or set the Steam presence the daemon announces for friends/chat
  language                         View or set the default Steam API language
  persona-wait                     View or set `user` status wait
  country                          View or set the price country
  experimental                     View or set the experimental-features gate
  steam-runtime-runner             View or set the Wine/Proton runner that hosts the Windows Steam runtime
  steam-runtime-policy             View or set the global default Steam-integration policy for launches
  install-resume                   View or set whether the daemon resumes interrupted installs when it starts. `manual` (default) waits for `install resume`; `auto` resumes `interrupted` backlog entries, never paused or stopped ones
  download-limit                   View or set the global download limit
  shader-precache                  View or set Vulkan shader pre-caching before `play` (Linux). `auto` (default) replays the game's Steam pipeline cache with `fossilize_replay` and points the driver caches at `steamapps/shadercache/<appid>`, like Steam; `off` leaves shaders to the game
  hide-uninstalled-launch-options  View or set whether `launch-options` hides entries whose executable isn't installed, for installed games. `on` (default) lists only entries `play` can start; `off` lists every entry, with `installed` in `--json`
  cloud-sync                       Steam Cloud sync around `play`
  anticheat-auto-install           View or set whether `play` auto-installs a missing Proton anti-cheat runtime (EasyAntiCheat / BattlEye) for a game that ships one. `on` (default) downloads it before the Proton launch, like Steam; `off` never downloads (install manually with `aurelia proton anticheat`)
  proxy                            View or set the network proxy used for all HTTP(S) communication
  game                             View or set per-game launch settings (Proton version, platform)
  clear-games                      Reset the per-game settings of ALL games to defaults (both stores)
  help                             Print this message or the help of the given subcommand(s)

Options:
  -j, --json        Emit output (and errors) as JSON. Works with every command
  -v, --verbose...  Increase log verbosity (repeatable: -v, -vv, -vvv). Without it only warnings and errors are logged. -v adds progress/debug logs and a launched game's own output; -vv/-vvv unmute the Steam networking stack so a stalled command shows where it is stuck. `RUST_LOG` / `AURELIA_LOG` override the logs
  -h, --help        Print help
